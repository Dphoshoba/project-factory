# Writing for humans

Follow `knowledge/06-writing-for-humans.md` at the root of this factory.
Scan for AI-tell patterns (puffery, filler, hedging, chatbot phrases, em
dashes, colons as connectors, bold-label lists, abstract metaphor nouns),
rewrite, then add back rhythm and opinion so the result doesn't read as
sterile as it is pattern-free.
